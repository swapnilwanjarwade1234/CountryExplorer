# 🌍 Country Explorer

A responsive website for exploring countries around the world. Search by country name to view its flag, capital, population, region, languages, and currencies.

## ✨ Features

- Search for countries by name
- View country flags and official names
- See capital cities, population, and region
- Explore languages and currencies
- Toggle between light mode and dark mode
- Keep up to five recent searches in browser storage
- Responsive layout for desktop and mobile
- Display helpful messages when a search fails

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- Browser Local Storage

## 🌐 Country Data API

This project retrieves country information from the [countries.dev API](https://countries.dev/).

An active internet connection is required to search for country information.

## 🚀 Run Locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` with the Live Server extension, or serve the folder using a local web server.
4. Enter a country name, such as `India`, `Japan`, or `Canada`.
